Projects

PulseGuard: IoT network anomaly detection

Capstone project · Melbourne Institute of Technology · Mar 2026 to Sep 2026

An ensemble machine learning system that flags malicious IoT network traffic, with a web dashboard for analysts. I was ML engineer and technical lead in a team of five.

97.5%recall on held-out IoT-23 test set
94.5%F1 score on the same set
21,533test flows evaluated
  • Cleaned and encoded the IoT-23 dataset, then compared unsupervised baselines (Isolation Forest, Local Outlier Factor) with a supervised Random Forest and XGBoost ensemble.
  • Built a Streamlit dashboard with role-based access control, multi-factor login, an admin page for user management, and upload-your-own-CSV analysis.
  • Tuned for high recall, so real attacks are less likely to be missed, and evaluated the trade-off with a confusion matrix on held-out data.
  • Applied client feedback directly and presented the work to staff and the client.
